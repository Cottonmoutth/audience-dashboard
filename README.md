# 관객 패턴 대시보드

KOBIS 일별 박스오피스를 매일 받아, 한국 극장 관객의 움직임을 하나의 웹페이지로 보여 줍니다.

**보기 → https://audience-dashboard-kappa.vercel.app/**

## 무엇을 보나

- **시장 전체 일별 관객수** — 올해 1/1부터 오늘까지, 평일·주말·공휴일을 색으로 구분
- **개봉 후 일차별 관객수 비교** — 영화를 최대 6편까지 골라 겹쳐 보기 (개봉 요일이 다르면 요일을 맞춰 정렬)
- **개봉 주차별 드롭률** — 전주 대비 증감을 히트맵으로, 올해 TOP20 중앙값과 비교
- **월간 박스오피스 흐름** — 달력 날짜를 고정해 한 달 치 영화별 곡선을 비교
- **요일 리듬** — 공휴일 없는 주만 모아 계산한 요일별 관객 지수

## 데이터

- 출처: 영화관입장권통합전산망(KOBIS) 일별 박스오피스
- 기간: 2026-01-01 ~ 전일
- 대상: 1/1 이후 관객 10만 명 이상인 영화 (지난해 개봉 후 올해까지 상영된 작품 포함)
- 시장 합계에는 그날 순위에 오른 모든 영화가 들어갑니다
- 일마감 후 보정으로 과거 수치가 바뀔 수 있습니다
